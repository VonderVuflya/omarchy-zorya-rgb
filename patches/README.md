# Pinned compatibility sources

`lianli-rgb-compat.patch` applies to [lian-li-linux](https://github.com/sgtaziz/lian-li-linux) commit `d262007c9bfbe87ae7c9d390d68ec74e5deb4d0a` (0.6.1). It contains the complete isolated, locally verified compatibility changes: RGB-only cooling/LCD guards, loopback SDK, idle and fragmented SDK connections, direct color/mode behavior, opt-in radiator control, sensor freshness and smoothing, retained PWM/RGB transactions, and safe resume re-exec. Upstream is MIT, copyright 2026 sgtaziz; its notice is retained in `LICENSE.lian-li-linux`. Modifications are distributed under the same MIT terms. Fresh Zorya installs run `--rgb-only` with no cooling settings; adopting an existing explicit configuration retains its cooling policy.

`kingston-rc3-spd.patch` applies to OpenRGB release candidate 1.0rc3 commit `6fbcf62d7694e7b92fd0a5884b40b92984fbd1b0`. Detection helpers were backported from upstream commit `4d17bac5b8f34746847e25bd42189cde8014f0cc`. It reads supported DDR5 SPD family/model metadata instead of rejecting known supported DIMMs with an unreliable first signature word. It does not write SPD or EEPROM, and excludes Limited Edition and v2 APIs. OpenRGB copyright belongs to its contributors; GPL-2.0-or-later source headers and original GPLv2 text remain in `LICENSE.OpenRGB`.

The installer fetches exact commits and verifies HEAD before applying patches. Source directories and patches remain available in the user data directory. FFmpeg `n8.0.1` commit `894da5ca7d742e4429ffb2af534fcda0103ef593` is built locally with minimal shared libraries and no codecs/programs enabled. Upstream LGPL-2.1-or-later notices and full source remain in that checkout. This is an RGB-only link dependency, not LCD/media support. EVDI userspace library `v1.14.14` commit `750044ce73cf2eec9178889c4f851f0ff01368b3` is built locally under its MIT license; no kernel module or DKMS install is performed.

A successful build is not proof of a physical RGB effect or a completed suspend/resume test. See the project compatibility report for tested hardware and remaining limitations.

The bundled Lian Li patch also narrows its user-local IPC socket from mode0666 to0600. Zorya validates the runtime directory, socket ownership/type and connected peer UID before sending any IPC request. Pairing is an explicit action for a currently listed unbound device; neither setup, discovery nor polling sends bind commands.

`lianli-onboard-replay.patch` applies after `lianli-rgb-compat.patch` under the same MIT terms. It preserves complete buffered animations during drift recovery, adds a read-only replay-safety capability probe, and bounds animation payloads. Cooling policy is unchanged.
