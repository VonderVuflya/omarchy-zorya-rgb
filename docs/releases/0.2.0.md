# ZoryaRGB 0.2.0

- Guided first setup checks the runtime and hardware connections, explains required actions and runs them only after you start setup.
- Runtime, OpenRGB, supported Lian Li and verification stages report progress separately. Errors stay visible; retry checks what still needs work.
- Working hardware SDK services are reused. Full-mode cooling/LCD services remain protected from replacement.
- Setup continues when the panel closes. Device selection and applying a test color remain explicit.
- Advanced diagnostics, wireless pairing and optional Kingston compatibility remain available.
- Project changes now use OpenSpec and reviewed pull requests; published versions have matching tags and GitHub Releases.

Primary target: Arch/Omarchy with base Python 3.11+. Runtime and hardware setup may download dependencies and ask for system authorization. No new clean-machine hardware build or physical suspend test is claimed for this release.
