# ZoryaRGB 0.3.2

- Fixed private Python environments following mise’s changing `latest` alias after an Omarchy update, which could hide the installed OpenRGB SDK.
- Runtime setup now preserves a backup, rolls back failed replacements and restarts the existing Zorya daemon before later installer steps.
- CLI launchers ignore inherited Python settings and retain system-Python diagnosis/setup when private Python cannot start.

Existing broken environments require the explicit runtime step in Setup. Saved lighting and hardware service configuration are preserved. Distribution Python ABI upgrades may still require rebuilding. A new physical suspend and clean hardware build were not performed for this fix.
