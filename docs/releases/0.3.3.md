# ZoryaRGB 0.3.3

- OpenRGB 1.0 servers that stall during the SDK handshake are now retried with protocol 3, so the distro `openrgb` package works without manual pinning (#3).
- One unknown or invalid field in saved state no longer wipes all scenes. An unreadable state file is kept as `state.json.corrupt-<time>` before it is replaced.
- When one device drops a shared OpenRGB connection, the other devices on it reconnect right away instead of stalling for up to 15 seconds.
- The panel opens on Setup while setup is still needed. The empty device list links to Setup and has a Rescan button. The "Color and effects" tab label is fixed.
- Status polling slows down while the backend is unavailable.
- Hardware setup on Arch installs only missing build packages and never core packages such as `systemd` or `python`. An interrupted source download no longer blocks later setup runs.
- Updates keep one source backup instead of accumulating copies.

Saved scenes and hardware setup are preserved. The OpenRGB 1.0 fallback is covered by mocked tests and was not checked against a physical 1.0 server. Panel changes were checked with offscreen QML tests, not in a live shell session.
