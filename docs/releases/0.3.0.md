# ZoryaRGB 0.3.0

- New ↑ update indicator checks stable GitHub Releases and offers a reviewed, version-specific update. UI and runtime update together with source backups and rollback on failed health verification.
- Replaced JSON Details with readable diagnostic report previews, including hardware models, drivers, versions, service status and captured errors/tracebacks.
- Create a GitHub issue with the full reviewed report through an authenticated gh CLI, or use the browser draft and full-report copy. Nothing is published automatically.
- Transient hardware failures remain reportable after recovery. Report sharing and updating are serialized to preserve operation results.
- Recorded merged-branch cleanup in the contributor/release workflow.

Updates preserve lighting state and hardware settings. Dependency changes and local git edits require explicit action. Diagnostic redaction is best effort; review the preview before publishing. Full hardware installation and physical suspend were not retested for this release.
