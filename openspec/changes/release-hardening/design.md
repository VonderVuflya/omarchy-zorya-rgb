## Decisions

1. **Protocol fallback.** openrgb-python 0.3.6 negotiates its default protocol (4+) and OpenRGB 1.0 closes the listener without replying. `connect_client` retries once with protocol 3 and a fresh deadline only when the first attempt timed out or the server closed the socket mid-negotiation. Refused or malformed connections are not retried. A successful fallback is cached for that address and port for 10 minutes, so a server that was only slow once gets the default protocol again later; the entry is dropped if protocol 3 fails. Pinned versions (the Lian Li bridge uses 1) are never changed. The cost is one extra packet timeout (3 s) per daemon start against such a server.
2. **Tolerant state loading.** Each known setting is validated on its own; invalid values keep their default and unknown keys are ignored (not preserved on write). Scenes are validated one by one and invalid scenes are dropped with a visible count. JSON that cannot be parsed or is not an object leaves defaults in memory, and the first write renames the old file to `state.json.corrupt-<unix time>`. Incoming `set` patches keep strict validation.
3. **Shared SDK socket.** The bounded transport closes the endpoint socket on any send or read failure. The backend now records each device's endpoint. When a device failure leaves its endpoint socket closed, later devices on that endpoint in the same pass report "reconnecting" without a retry delay, and the daemon refreshes the endpoint on the next loop instead of after the 15 s discovery interval. The failing device keeps its own 5 s retry delay, which bounds reconnect attempts.
4. **Arch dependencies.** Only packages reported missing by `pacman -Qq` are requested; groups are expanded to members. `systemd` and `python` are checked and, if missing, setup stops and asks for a full system upgrade, since installing single core packages risks a partial upgrade.
5. **Update backups.** After a verified update, older `.<plugin>.before-update-*` copies are removed and only the newest `.<plugin>.failed-update-*` copy is kept. Only these exact prefixes are touched and cleanup errors never roll back a completed update.
6. **Panel polling.** The 4 s poll doubles after each failed read up to 30 s and returns to 4 s after a successful read, an action, panel open or Rescan.

## Not Changed
Release tag signing, removal of system udev/modules-load files on uninstall and narrowing the I2C access rule need separate decisions and hardware checks; they are tracked for a later change.

## Verification
Mocked tests cover protocol fallback (timeout, wrapped timeout, early close, refused, malformed, pinned, both failing, cached), tolerant loading, corrupt-file backup, shared-socket reconnect, Arch package selection, checkout recovery, metadata atomicity and backup pruning. The suite passes with the pinned SDK installed. Panel behavior is covered by source and offscreen QML tests; it was not exercised in a live shell session, and OpenRGB 1.0 negotiation was not tested against a physical server.
